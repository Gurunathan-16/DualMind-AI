# Cost & Latency Analysis

| System             | Hosting Type        | Estimated Cost | Avg Latency |
| ------------------ | ------------------- | -------------- | ----------- |
| OSS Assistant      | Hugging Face Spaces | Free / Low     | Moderate    |
| Frontier Assistant | Groq API            | API-based      | Low         |

## Observations

### OSS Assistant

* Lower deployment cost
* Fully controllable
* Higher latency on CPU hardware

### Frontier Assistant

* Faster inference
* Better scalability
* Requires paid API usage at scale

## Conclusion

Hosted frontier models provide superior speed and quality, while OSS models offer lower operational costs and deployment flexibility.
