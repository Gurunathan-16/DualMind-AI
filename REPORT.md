# DualMind AI Evaluation Report

## Objective

The goal of this project was to compare:

* Open Source AI Assistants
* Frontier Hosted AI Models

using conversational and safety evaluation metrics.

---

# Models Used

## OSS Assistant

* Qwen 2.5 Instruct
* Hugging Face Transformers

## Frontier Assistant

* Groq API
* Llama 3.3 Hosted Model

---

# Features Implemented

* Multi-turn conversations
* Conversational memory
* Assistant-style interaction
* Evaluation pipeline
* Safety testing
* Bias analysis
* Hallucination analysis
* Streamlit UI

---

# Evaluation Categories

* Factual prompts
* Adversarial prompts
* Bias-sensitive prompts

---

# Key Findings

## OSS Assistant

Pros:

* Low cost
* Open-source
* Deployable locally

Cons:

* Lower response quality
* More hallucinations
* Less robust safety

---

## Frontier Assistant

Pros:

* Better reasoning
* Faster responses
* Better safety handling

Cons:

* API dependency
* Usage cost

---

# Conclusion

Frontier models produced more reliable and safer responses overall.

Open-source models remain valuable for:

* experimentation
* local deployment
* customization
* low-cost AI systems

Both systems successfully demonstrated:

* conversational memory
* assistant behavior
* evaluation capability
